# Project notes

Read this before changing anything. It records decisions that are easy to undo
by accident, and mistakes that have already been made once.

## What this is

**StarShooter** — a private HKDSE study desk. Vanilla ES modules, no build step,
no framework, no bundler. A Vercel Node function in `api/index.js` and one
router in `server/routes.js`; MongoDB Atlas for storage.

The product is small, but two areas carry real rules: the **grading** (it must
use published DSE figures and nothing else) and the **Android shell** (a WebView
around the same deployed site). Read the relevant section before touching
either.

## The rules that are easy to break

### Grading uses published figures only

- Grade boundaries come from `public/data/cutoffs.json`, which is generated by
  `scripts/fetch-cutoffs.mjs` from DSE00's tables. **Never hand-edit bands in
  the app, and never add an input that lets a student set their own.**
  `lib.bandsFor()` and friends ignore any stored `gradeBands` on purpose.
  Several tests assert that a stored band set changes nothing — if you
  "restore" editable bands, those tests will fail correctly.
- The boundaries panel shows the **mean of the last five sittings**, per paper
  where the source publishes per-paper rows. Chinese is marked per paper with
  different totals, so `recentPaperBoundaries()` must win over a subject-wide
  blend.
- Order is highest first: `GOAL_GRADES = ['5**', '5*', '5', '4']`.
- All six levels show published values. Do not fall back to the generic
  `DEFAULT_BANDS` (35/45/55/65/75/85) for a subject that has real data.
- CSD has no levels: it is Attained / Not attained.
- Chinese has **no Paper 3 from 2024**. Pre-2024 sittings still offer P3/P4.

### Subjects and names

- Every subject name is **English**. The catalog in `server/util.js` is the
  single source; do not add Chinese names to the UI.
- Four cores are seeded on sign-up: Chinese Language, English Language,
  Mathematics, Citizenship & Social Development.

### Deleting

A delete must actually delete the record. Never write a null/empty score in
place of a removed attempt — an older bug did exactly this and left ghost rows.
`removePaperCell()` exists because the matrix deletes by cell (subject, year,
paper), not by row id, so a replaced row cannot survive a delete.

### Matrix cells are both "log" and "edit"

Every cell renders one button with `data-act="log-paper"`, whether or not a
paper is logged. The handler in `actions.js` **must** look for an existing
attempt for that cell and open it as a record; otherwise a filled cell opens a
blank form and the student loses the Delete button. This is covered by a test
that fails if you remove the lookup.

## Testing

```bash
npm run test          # 41 isolation checks — needs no database
npm run test:ui       # 61 UI checks — needs jsdom
npm run test:native   # 6 Android-shell checks — needs jsdom
node test/cutoffs.test.mjs   # 9 grading checks
```

Run all four before claiming something is fixed. Two traps:

- `test/ui.test.mjs` supports async checks now. If you add a check that returns
  a promise, it is awaited; if you write a synchronous check that leaves work
  pending, it will assert against a stale DOM. Use `tick()`.
- jsdom is a normal dependency, so `npm install` is enough to run the UI and
  native suites. If `node_modules` is absent they print "skipped" and exit 0 —
  a green tick that proves nothing. Check the count, not just the exit code.

## Android shell (`android/`)

A thin WebView, no third-party libraries, no Gradle. It holds **no copy of the
app** and **no keys**: it loads the deployed site, so a redeploy updates it.
The MongoDB URI stays in Vercel.

- The URL lives in one place: `res/values/strings.xml` → `app_url`.
- Build with `ANDROID_SDK=… ./android/build.sh`. Keep `keystore.jks`; updates
  only install over an existing app if signed with the same key.
- **The build script must fail loudly on a javac error.** It did not, once, and
  produced a signed APK from incomplete code. Do not reintroduce `|| true` on
  the compile step.
- A WebView cannot follow a `data:`/`blob:` download. `public/native.js`
  intercepts those clicks and hands the text to Java; without it the recovery
  code and JSON export buttons are silently dead. `test/native.test.mjs` guards
  this.
- System bars are transparent and the page draws under them. The page pads for
  the notch with `env(safe-area-inset-*)`. Keep that pairing: making the bars
  opaque again brings back a strip of the wrong colour.
- `onBackPressed` walks WebView history before leaving the app.

## Layout traps already hit

- Grid/stack children default to `min-width: auto`, so a wide table inside one
  card stretched the whole page and pushed the tab bar off screen. `.grid > *`
  and `.stack > *` are pinned to `min-width: 0`. Do not remove that.
- `table.plain` has a 480px minimum for the wide data tables. A two-column
  key/value table must carry the `kv` class, which drops the minimum and wraps.
- Toasts move to the top while a dialog is open (`[data-modal-open]`), because
  a bottom toast covered the sheet's action row and hid the Delete button.

## Visual rules

- No gradients. Nothing that reads as generic AI-generated UI.
- Squared-paper background, 28px cells, drawn as two CSS hairlines.
- Light `#f8f6f1`, dark `#0d1210` (a green cast, not neutral grey).
- Accent `#10574b` light / `#7fd0b6` dark. Gold `#8a6d1f` / `#e0c383`.
- IBM Plex Sans + Newsreader, self-hosted in `public/fonts/`. No CDN fonts.
- The logo is a four-cell matrix with one gold cell: `public/logo.svg`, and the
  PNG icons in `public/icons/` are generated from it. The maskable icon is a
  separate full-bleed file.
- No school- or subject-specific placeholder text.

## Deploying

Vercel only. **Vercel Drop does not work** — it serves a static site and never
registers `/api`. Use the GitHub import or `npx vercel --prod`.

`MONGODB_URI` must be set before the build. Atlas Network Access must allow
`0.0.0.0/0` because Vercel functions have no fixed egress IP.

The route travels in a query string (`/api?__p=me`) rather than a catch-all
path, so `vercel.json` can stay as just `{"outputDirectory": "public"}`.

## Working with the user

- This is a real student's app. Keep claims to what the tool output actually
  shows: say "verified in the browser at phone width", not "works on mobile",
  when no device was involved.
- Nothing is deployed automatically. When you change `public/`, say a redeploy
  is needed — the APK loads the live site and picks it up without a rebuild.
- Never paste credentials into chat, a commit, or a project file. If one has
  been shared, say to rotate it in Atlas → Database Access.
